# Task List Frontend

Frontend React com Bootstrap, Formik e validação usando Yup.

## Como usar

1. Abra o terminal em `frontend`
2. Instale as dependências:

```bash
npm install
```

3. Execute o projeto:

```bash
npm run dev
```

4. Abra o navegador em `http://localhost:5173`

## Configuração de API

O frontend usa `http://localhost:3000` como `VITE_API_URL` padrão.

Se o backend estiver em outro endereço, crie um arquivo `.env` com:

```env
VITE_API_URL=http://localhost:3000
```
